# BurnerEye Grad-CAM

Откройте `run.bat` двойным щелчком. В PyCharm можно запустить `gradcam_gui.py`, выбрав интерпретатор `BurnerEye Trainer\.venv\Scripts\python.exe` из соседнего проекта. Приложение использует это окружение и штатную предобработку кадров из `BurnerEye Trainer`.

1. В поле **Папка с видео** выберите каталог набора данных. Приложение просматривает и вложенные папки. Для файла `S400D600_test.mkv` оно определит режим S400D600 и тестовую выборку. Поддерживается также раскладка `S400D600/test/clip.mkv`. При нескольких тестовых файлах выберите строку режима и нужный файл в выпадающем списке под таблицей.
2. В поле **Папка модели** выберите каталог запуска обучения, содержащий `model/best_model.pt`. Можно выбрать и саму подпапку `model`.
3. Укажите, куда сохранить графики, и нажмите **Построить и сохранить**. По умолчанию берутся 12 равномерно распределённых окон на видео. Для `average8` в каждом окне восемь соседних кадров, для модели с GRU длительность и число кадров берутся из чекпойнта.

Справа доступны обзор, положительный и отрицательный Grad-CAM и три варианта окклюзии. На каждой фигуре есть строки всех выбранных режимов. Эффект окклюзии измеряется в г/ч и вычисляется как прогноз до маски минус прогноз после маски.

Пять PNG-файлов и `windows.json` сохраняются в подпапке с именем папки модели. Повторный запуск сохраняется в датированной подпапке. Манифест содержит выбранные видео, таймкоды, прогнозы и параметры расчёта. CUDA используется автоматически при наличии.
